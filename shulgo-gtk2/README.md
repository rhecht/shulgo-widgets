# ShulGo for GNOME 2

The next minyan near you, in the notification area of a 2007 desktop. Built for Jewbuntu Classic —
a remaster of the original Ubuntu 7.10 "Gutsy" — which means **Python 2.5.1 and PyGTK 2.12 on a
Pentium II or III with 128 to 512 MB of RAM**.

## Why this exists when there are already four ShulGo widgets

The Xfce widget is the closest relative and it cannot run here: it needs Python 3 and GTK 3, and
this machine has neither and never will. Everything above GTK 2.12 is a decade too new.

What is shared is the part that matters. `shulgo-core/format.js` is the canonical wording for every
ShulGo client, and `shulgo_gtk2/fmt.py` is a port of it, as `shulgo-xfce` has its own port for
Python 3. Three copies of the wording would be an unforced error if nothing held them together;
what holds them together is `tests/test_fmt.py`, which checks all 166 cases against answers
generated by running the real JavaScript. The three cannot drift apart without a test failing.

## What Python 2.5 does not have

Every one of these was found by running the code against the real 2.5.1 from the Gutsy filesystem,
not by reading a changelog, and every one of them was silent or near-silent:

| Missing | Since | What this does instead |
|---|---|---|
| `Decimal(a_float)` | 2.7 | pulls the double apart with `frexp` and rebuilds it exactly |
| `Decimal.scaleb` | 2.6 | `Decimal('1e-%d')` |
| `math.isnan`, `math.isinf` | 2.6 | NaN is the value not equal to itself; infinity by comparison |
| `next(iterator)` | 2.6 | a `for` loop with `break` |
| `b''` literals | 2.6 | plain `''`, which is already bytes here |
| `except X as e` | 2.6 | `except X, e` |
| `from __future__ import unicode_literals` | 2.6 | a `u` prefix on every literal, put there by `tools/unicodeify.py` |
| the `json` module | 2.6 | `simplejson`, as a visible dependency |
| `str.format` | 2.6 | `%` |
| dict and set comprehensions | 2.7 | plain loops |
| `os.replace` | 3.3 | `os.rename`, atomic on POSIX |
| `open(encoding=)` | 3.0 | `codecs.open` |
| `gtk.show_uri` | GTK 2.14 | launches `xdg-open`, `gnome-open` or `firefox` by hand |
| `set_tooltip_text` | GTK 2.16 | `gtk.StatusIcon.set_tooltip`, plain text only |
| `gobject.timeout_add_seconds` | PyGObject 2.14 | `gobject.timeout_add`, in milliseconds |

Two that are not about missing features and cost more than all of the above:

**`5 / 60` is `0`.** Without `from __future__ import division`, every countdown would have been
wrong, and wrong in the direction that reads as "now".

**`str(u'café')` raises.** `simplejson` returns unicode for every string in the API's answer, so one
shul with an accent in its name would have taken the whole widget down — on the one machine whose
owner has no way to read a traceback. There is no bare `str()` in this package. Everything is
unicode end to end and is encoded to UTF-8 once, at the GTK boundary.

**`IOError` is not `OSError`.** They are separate classes on Python 2, and a failed file read raises
the first. An `except OSError` around the config read meant a traceback on the very first run — the
one run where, by definition, there is no config file yet.

## HTTPS, and why the key is not on the command line

Ubuntu 7.10 ships OpenSSL 0.9.8, which speaks TLS 1.0 and nothing later, and Python 2.5's `urllib2`
is built against it. shulgo.com will not accept TLS 1.0, so **every call the standard library could
make is refused before a byte of HTTP happens**. Nothing in Python fixes that; the problem is
underneath Python. So the ISO ships a statically linked modern curl at `/opt/jewbuntu/bin/curl` and
every request goes through it as a subprocess.

The obvious way to send the key through curl is `-H "Authorization: Bearer …"`, and it is wrong: a
process's arguments are world-readable, so any other account on the machine can read the key out of
`ps` during the poll. A 2007 family desktop is exactly the machine with four accounts on it. So
headers go in a config file written `0600` and deleted the moment the call returns, and curl reads
it with `-K`. POST bodies go the same way, with `--data @file`. Nothing secret is ever an argument.

## Linking, without typing a password

The widget never sees a password. It asks ShulGo for a short code, you type that code into
shulgo.com on a machine with a keyboard you trust, an administrator approves it, and the key comes
back. If the machine has no internet, it says so *first* — told "ask your administrator" while
offline, somebody will go and ask, and then wait for nothing.

A linking you walk away from is written down, so closing the window does not throw it away. That
cost a real person two rounds of approvals before it was fixed in the GTK3 build.

## A line on the top panel

Same contract as the Xfce widget: the widget keeps `~/.cache/jewbuntu/shulgo-bar.txt` current, the
panel only reads it. A stale list is marked `(old)` at the cost of the countdown, because a frozen
line that looks current is worse than one with no countdown on it.

## Installing

```
make install DESTDIR=debian/shulgo-gtk2 PREFIX=/usr
```

Installs the program under `/usr/lib/shulgo-gtk2`, `shulgo-gtk2` into `/usr/bin`, an SVG and 22, 24
and 48 px PNGs into hicolor, a menu entry, and an autostart entry in `/etc/xdg/autostart`. The PNGs
are not optional: a 2007 install may have no librsvg pixbuf loader, and a tray icon that fails to
load is not an error anybody sees — it is an empty space where the widget should be.

`python -m` does not run packages until 2.7, so `bin/shulgo-gtk2` is a shell script that sets
`PYTHONPATH` and calls `main()`.

## Checking an install

```
shulgo-gtk2 --check
```

Reports the PyGTK and simplejson versions, whether there is a display, **whether the bundled curl is
there and is the bundled one**, where the icon resolved to, and whether a key and place are set. It
exists because on this hardware the usual failure is not a crash: it is a widget that starts, draws
nothing, and is never mentioned again.

## Tests

```
TZ=America/Toronto python tests/test_fmt.py
```

Run them under real Python 2.5, in the Gutsy image — the fixtures catch wording drift, but only the
real interpreter catches a `b''` or an `except X as e`. `tools/py25lint.py` flags the common ones
before the container has to, and `tools/unicodeify.py` puts the `u` prefixes on.

Nothing in the suite skips itself. A test that quietly opts out is how the same-words check went
missing from every Arch package built after the day its fixture was generated.
