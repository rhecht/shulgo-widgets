How far ahead

Menu bar

API key

Ask your ShulGo administrator for a key. It is kept in a file only you can read, and never in this window.

The mikvah listings come from mikvah.org, whose terms keep them to ShulGo’s own apps. A key you ask for reads everything else — minyanim, events, zmanim — but the Mikvaos tab stays hidden. If you run ShulGo yourself, an admin can issue a key of the kind that includes them under Admin › System › API & apps.
